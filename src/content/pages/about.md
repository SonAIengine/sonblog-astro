AI 플랫폼 엔지니어 손성준입니다. 이곳은 제가 직접 만들고 운영한 기술 작업을 기록하는 개인 블로그입니다. 커머스 검색 엔진에서 출발해 AI 에이전트 플랫폼까지, 실무와 사이드 프로젝트에서 배운 판단과 시행착오를 남깁니다.

지금은 플래티어 AI R&D팀에서 8명 파트를 이끌며 AI 에이전트 플랫폼 XGEN의 배포와 모델 서빙을 맡고 있습니다. 고객사 3곳과 사내 5개 환경을 Helm 차트 하나로 운영하고, GPU 서버마다 모델 서버를 띄워 요청을 알맞은 서버로 보내는 구조를 만들었습니다. 최근에는 에이전트 하네스를 공개 벤치마크로 평가하며 작업당 LLM 호출을 평균 8.21회에서 4.5회대로 줄였습니다.

그 전에는 커머스 상품 검색을 맡아 키워드, 상품 벡터, 색상 벡터를 한 번에 묻는 OpenSearch 하이브리드 쿼리를 설계했고, Rust 검색 API 전환에서 색인 파이프라인을 스트리밍 방식으로 다시 짰습니다.

회사 밖에서는 LLM 에이전트가 쓸 도구를 찾아 주는 graph-tool-call을 만들어 공개하고 있습니다. 결과가 좋지 않았던 실험도 그대로 기록합니다.

글은 대부분 제가 실제로 부딪힌 문제를 기준으로 씁니다. 완성된 정답보다 "왜 이런 선택을 했는지", "어디서 깨졌는지", "다시 한다면 무엇을 바꿀지"를 남기는 쪽에 가깝습니다.

## 전문 영역

- **AI / LLM**: vLLM·llama.cpp 모델 서빙, AI 에이전트 하네스 평가, MCP, 도구 검색
- **DevOps**: K3s, Helm, ArgoCD, 배포 파이프라인
- **Search Engine**: OpenSearch 하이브리드 검색, 벡터 검색, Rust 검색 API
- **Full Stack**: Next.js, NestJS, Rust, Python
